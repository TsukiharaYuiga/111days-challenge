# 111日間チャレンジ｜創作・開発・読書

2026年11月10日から2027年2月28日までの111日間で、小説・ソフトウェア開発・書評の3分野に取り組む個人制作プロジェクトです。

小説33件、開発33件、書評33件の合計99件を目標にしています。

完成作品だけでなく、制作過程での学習、失敗、改善、AIの利用方法も記録し、活動を通じた成長を確認できるようにします。

## 開発分野の目的

開発分野では、30件の小規模演習と3件のマスター作品、合計33件を制作します。

単にAIにプログラムを生成させるのではなく、自分でコードを理解し、動作を検証し、改善できる技術力を身につけることを目標としています。

特に以下の能力の習得を重視します。

- Python・JavaScriptによる基礎的なプログラミング
- ファイル操作・データ処理・データベース
- WebアプリケーションとAPIの開発
- テスト・デバッグ・エラー処理
- 生成AIを活用したアプリケーション開発
- AI生成コードの理解・評価・検証

## 制作・学習の方針

開発では次の流れを基本にします。

1. 制作する機能と完成条件を決める
2. 自分で設計・実装を試みる
3. 必要に応じてAIから説明や改善案を得る
4. 仕組みを理解したうえで修正する
5. 実際に動作を確認する
6. READMEと学習記録を残す
7. 成果物を公開する

AIに任せた内容と本人が実装・判断・検証した内容を区別し、コードを説明できる状態を目指します。

## AIの利用について

本プロジェクトでは、ChatGPTなどの生成AIを学習・開発の補助として使用します。

主な用途は、技術的な解説、コードレビュー、デバッグ支援、テスト方法の検討、ドキュメント草案の作成などです。

AIが提案したコードについても、可能な範囲で動作確認と理解度の確認を行います。

## 成果物の見方

各開発作品のフォルダには、原則として以下を保存します。

- ソースコード
- README（目的・使用技術・実行方法・制約）
- 必要に応じたテストコードや動作資料

開発の進展とともに、公開可能な範囲で内容を追加していきます。
