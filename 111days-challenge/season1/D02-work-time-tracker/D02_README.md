# D02｜Work Time Tracker（作業時間集計ツール）

## 1. 概要

Pythonを用いて、作業名と作業時間を記録し、合計時間の計算とJSONファイルへの保存を行うCLIツールです。

111日間企画の開発成果物D02として制作しました。

D01で学んだ繰り返し処理とリスト操作を応用し、辞書によるデータ管理、例外処理、JSON形式でのファイル保存を学ぶことを目的としています。

## 2. 動作環境

- Python 3
- ターミナルまたはコマンドプロンプト
- 外部ライブラリ不要（標準ライブラリ`json`を使用）

## 3. 実行方法

`D02_Final.py`を保存したフォルダで、次のコマンドを実行します。

```bash
python D02_Final.py
```

作業名と作業時間（分）を入力します。

作業名に「終了」と入力すると、記録の一覧と合計時間を表示し、`work_log.json`に保存します。

### 実行例

```text
作業名：Python学習
作業時間（分）：40
作業名：小説執筆
作業時間（分）：30
作業名：終了

---本日の作業記録---
Python学習: 40分
小説執筆: 30分
合計：70分
```

## 4. 主な機能

- 作業名と作業時間の入力
- 複数の作業記録の保持
- 作業記録の一覧表示
- 合計作業時間の算出
- JSONファイルへの保存
- 数値以外を入力した際の例外処理

## 5. JSON保存形式

出力される`work_log.json`の内容例：

```json
[
    {
        "task": "Python学習",
        "minutes": 40
    },
    {
        "task": "小説執筆",
        "minutes": 30
    }
]
```

JSONファイルは、プログラム実行時の作業ディレクトリに保存されます。

## 6. 学習・実装内容

### リストと辞書

1件の作業記録を辞書で表現し、リストに追加することで複数の作業を管理しています。

### 合計時間の計算

入力された作業時間を加算し、合計値を表示します。

### 例外処理

`try`・`except ValueError`を使用し、整数に変換できない入力があった場合、エラーメッセージを表示して入力処理を継続します。

### JSON保存

`json.dump()`を利用してリストと辞書をJSON形式で保存します。

`ensure_ascii=False`で日本語をそのまま保存し、`indent=4`で読みやすく整形します。

## 8. 既知の制約

- JSONファイルは毎回上書き保存され、過去の履歴は蓄積されません。
- 保存したJSONを読み込む機能はありません。
- 日付による記録の分類には対応していません。
- 整数の分単位のみ対応しています。
- 保存先への書き込み失敗時の例外処理は未実装です。
