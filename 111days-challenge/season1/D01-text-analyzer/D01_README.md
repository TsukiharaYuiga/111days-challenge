# D01｜Text Analyzer（文章分析ツール）

## 概要

Pythonで制作した、入力文章の文字数と行数を計算するCLIツールです。

111日間企画の開発成果物D01として、Pythonの基本文法、リスト操作、繰り返し処理、文字列結合を学習するために制作しました。

## 動作環境

- Python 3
- ターミナルまたはコマンドプロンプト
- 外部ライブラリ不要

## 実行方法

`D01_Final.py`を保存したフォルダで、次のコマンドを実行します。

```bash
python D01_Final.py
```

文章を1行ずつ入力し、何も入力せずEnterキーを押すと集計結果が表示されます。

## 使用例

入力：

```text
abc
def
```

次に空行を入力すると、以下が表示されます。

```text
文字数：7
行数：2
```

## 主な機能

- 複数行の文字列入力
- 文字数の計算（改行を含む）
- 入力行数の計算
- 空行による入力終了

## 実装上のポイント

- `while True`：文章の入力を繰り返す
- `if`と`break`：空行で繰り返しを終了する
- `list.append()`：入力した各行をリストに保存する
- `"\n".join()`：リスト内の文字列を改行で結合する
- `len()`：文字列長とリストの要素数を求める

## 動作テスト

| テスト | 期待値 | 結果 |
|---|---|---|
| 1行の日本語入力 | 5文字・1行 | 成功 |
| 空入力 | 0文字・0行 | 成功 |
| 英字2行 | 7文字・2行 | 成功 |
| 日本語・英字の混合2行 | 7文字・2行 | 成功 |

2026年11月12日、上記4ケースをPythonで実行確認。

## 既知の制約

- 空行は入力終了として扱うため、本文中に空行を含められません。
- 日本語の単語分割には対応していません。
- 文字数はPythonの`len()`に基づくため、見た目上の文字数と一致しない場合があります。
- ファイルからの読み込みには対応していません。
- 入力開始時の操作案内は表示されません。
