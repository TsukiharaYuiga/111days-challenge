# D05｜CSV成績分析ツール

## 1. 概要

Pythonで制作した、CSVファイルから成績データを読み込み、受験者数・平均点・最高点・最低点を計算するCLIアプリケーションです。

111日間企画の開発第5作として制作しました。

D01〜D04で学んだリスト、繰り返し処理、数値計算、条件分岐、例外処理を応用し、新しくCSV形式のデータ処理を学ぶことを目的としています。

## 2. 制作目的

- Python標準ライブラリ`csv`の基本操作を学ぶ
- `csv.DictReader()`でCSVファイルを読み込む
- 文字列として取得した点数を整数へ変換する
- 平均点・最高点・最低点を計算する
- 空データや不正データによる問題を防ぐ
- エラーの種類に応じて適切な案内を表示する

## 3. 動作環境

- Python 3
- ターミナルまたはコマンドプロンプト
- 外部ライブラリ不要
- 使用ライブラリ：`csv`（Python標準ライブラリ）

## 6. 実装した機能

### CSVの読み込み

`csv.DictReader()`を使用し、CSVの各行を列名で参照します。

```python
with open("scores.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)
```

### 点数の集計

各行から点数を取得し、整数へ変換します。

```python
score = int(row["score"])
```

点数が0〜100の範囲内であることを確認してから、人数・合計点・点数リストを更新します。

### 平均・最高・最低点の計算

受験者が1人以上の場合、以下の集計を実行します。

- 平均点：合計点 ÷ 受験者数
- 最高点：`max()`
- 最低点：`min()`

受験者が0人の場合は計算を実行せず、メッセージを表示します。

### エラー処理

以下のケースに対応しています。

- CSVファイルが存在しない
- 点数を整数に変換できない
- `score`列が存在しない
- 点数が0〜100の範囲外
- 点数欄が空欄
- 必要な列の値が不足している

`FileNotFoundError`と、`ValueError`・`KeyError`・`TypeError`を区別して捕捉します。

## 8. 学習内容

### CSVの取り扱い

`csv.DictReader()`で、列名を利用して各行のデータへアクセスする方法を学びました。

### 集計処理

リストと繰り返し処理を使い、人数・合計点・平均点・最高点・最低点を計算しました。

### 境界条件

合計点が0点でも、受験者が存在すれば平均点を計算できることを学びました。

平均点の計算可否は、合計点ではなく受験者数によって判断します。

### 例外処理

ファイルが見つからない場合と、ファイル内部のデータが不正な場合を区別する方法を学びました。

## 9. 既知の制約

- `scores.csv`という固定ファイル名を使用します。
- CSVはUTF-8形式を想定しています。
- `name`列の内容は集計に使用していません。
- 点数は0〜100の整数のみ対応しています。
- 小数の点数には対応していません。
- 不正な行がある場合は、集計全体を中止します。
- 完全な空ファイルも「受験者なし」として扱います。
- CSVの全列について厳密な形式検証を実施しているわけではありません。
- エラーの詳細な行番号は表示しません。
- 集計結果のファイル保存には対応していません。
- GUI・グラフ表示には対応していません。
