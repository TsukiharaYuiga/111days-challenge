# D03｜Reading Log CLI（読書記録ツール）

## 1. 概要

Pythonで制作した、書籍情報の登録・一覧表示・書名検索・JSON保存を行うCLIアプリケーションです。

111日間企画の開発成果物D03として制作しました。

D01で学んだリストと繰り返し処理、D02で学んだ辞書・JSON保存・例外処理を応用し、保存したデータをプログラムの再起動後にも利用できるようにすることを目標としました。

## 2. 制作目的

- リストと辞書を使ったデータ管理を復習する
- メニュー選択による処理の分岐を実装する
- 書名の部分一致検索を学ぶ
- JSONファイルの保存と読み込みを実装する
- AIの解説を参考にしながら、既習内容を自分で応用する

## 3. 動作環境

- Python 3
- ターミナルまたはコマンドプロンプト
- 外部ライブラリ不要（標準ライブラリ`json`を使用）

## 4. 実行方法

`D03_Final.py`を保存したフォルダで、次のコマンドを実行します。

```bash
python D03_Final.py
```

起動すると以下のメニューが表示されます。

```text
=== 読書記録 ===
1. 本を登録
2. 登録した本を一覧表示
3. 本を検索
4. 終了
```

半角または全角の数字で操作できます。

### 本を登録する

メニューで`1`を選択し、書名と著者名を入力します。

```text
選択：1
書名：こころ
著者：夏目漱石
登録しました。
```

登録すると、書籍情報が`book_log.json`に保存されます。

### 登録した本を一覧表示する

メニューで`2`を選択します。

```text
選択：2
1.こころ/夏目漱石
```

### 書名を検索する

メニューで`3`を選び、検索語を入力します。

```text
選択：3
検索する書名：ここ
こころ / 夏目漱石
```

書名の一部が一致した本を表示します。

一致する本がない場合は「該当する本はありません。」と表示します。

### 終了する

メニューで`4`を選択します。

## 5. 主な機能

- 書名と著者名の登録
- 複数の書籍情報の管理
- 登録順での一覧表示
- 書名の部分一致検索
- 検索結果がない場合のメッセージ表示
- JSONファイルへの保存
- 起動時のJSONファイル読み込み
- 保存ファイルが存在しない場合の空リスト初期化
- 半角数字・全角数字によるメニュー操作

## 6. JSON保存形式

登録データは`book_log.json`に保存されます。

保存形式の例：

```json
[
    {
        "book": "こころ",
        "author": "夏目漱石"
    },
    {
        "book": "吾輩は猫である",
        "author": "夏目漱石"
    }
]
```

保存先はプログラム実行時の作業ディレクトリです。

次回起動時には、保存されたJSONファイルを読み込み、書籍情報を復元します。

※`book_log.json`は個人の読書記録を含む可能性があるため、GitHubでは原則として公開しません。

## 7. 実装・学習内容

### リストと辞書

1冊の書籍情報を辞書で表現し、複数の辞書をリストに保存しています。

### enumerate()

`enumerate(books, start=1)`を使い、登録した書籍に1から始まる番号を付けて表示しています。

### 部分一致検索

`in`演算子を使い、検索語が書名に含まれているかを判定します。

検索結果が見つかったかどうかは`found`という真偽値で管理しています。

### JSONの保存と読み込み

- `json.dump()`：PythonのデータをJSON形式で保存
- `json.load()`：JSONファイルからPythonのデータを読み込む
- `FileNotFoundError`：保存ファイルがない場合に対応

D02で実装した保存処理に加えて、今回は起動時の読み込みを実装しました。

## 9. 既知の制約

- 空欄の書名・著者名を入力した場合は登録せず、メニューに戻ります。
- 空欄の検索語はすべての書名に一致します。
- 検索時には大文字・小文字を区別します。
- 書籍情報の編集・削除には対応していません。
- 著者名での検索には対応していません。
- JSONファイルが壊れている場合の例外処理は未実装です。
- ファイルの読み書きに失敗した場合の例外処理は限定的です。
- 同じ書籍を重複登録できます。
- 保存ファイルは実行時の作業ディレクトリを基準に読み書きします。
- GUIには対応していません。
