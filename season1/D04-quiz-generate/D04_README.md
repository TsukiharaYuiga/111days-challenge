# D04｜クイズ生成・採点アプリ

## 概要

Pythonで制作した、四択問題をランダムに出題し、回答を採点するCLIアプリケーションです。

111日間企画の開発第4作として制作しました。

JSONファイルに定義した問題から指定数を重複なく抽出し、正誤判定と正答率の計算を行います。

## 制作目的

- `random.sample()`によるランダム抽出を学ぶ
- `if`文による条件分岐と正誤判定を実装する
- リスト・辞書・JSONの操作を復習する
- `try`・`except ValueError`による入力検証を行う
- 正常入力だけでなく、境界値・異常入力を検証する

## 動作環境

- Python 3
- 外部ライブラリ不要
- 使用する標準ライブラリ：`json`、`random`

```text

```

## 実行方法

Pythonファイルと`questions.json`を同じフォルダに配置します。

ターミナルでそのフォルダを開き、以下を実行してください。

```bash
python D04_Final.py
```

プログラムが開始すると、出題する問題数を指定できます。

```text
===Pythonクイズ===
問題数を決めてください：3

第1問：Pythonで条件分岐を行うキーワードは？
1:when
2:switch
3:if
4:check

回答：3
正解！
```

全問の回答が終わると、正解数と正答率が表示されます。

```text
結果：3問中、2問正解
正答率66.7%
```

出題順はランダムなので、毎回異なる場合があります。

## 主な機能

1. JSONファイルから問題データを読み込む
2. 出題数を指定する（現在は1〜5問）
3. 問題を重複なくランダムに抽出する
4. 四択の選択肢を表示する
5. 回答の正誤を判定する
6. 不正な入力時に再入力を促す
7. 正解数と正答率を小数第一位まで表示する

## 問題データ

問題は`questions.json`で管理しています。

```json
{
    "id": 1,
    "question": "Pythonでリストの末尾に要素を追加するメソッドは？",
    "choices": [
        "append()",
        "add()",
        "insert_end()",
        "push()"
    ],
    "correct_index": 0
}
```

`correct_index`は0から始まる番号です。

画面に表示する選択肢は1から始まるため、回答番号から1を引いて比較します。

現在はPython基礎に関する5問を収録しています。

問題文はAIが作成した草案を使用しています。

## 学習内容

### random.sample()

指定した数の要素を、重複なしでランダムに取り出す方法を学びました。

### 条件分岐

回答番号と正解番号を比較し、正解・不正解に応じて処理を分けました。

### 入力検証

`try`と`except ValueError`を使用し、整数に変換できない入力へ対応しました。

また、出題数や回答番号が有効な範囲にあるかも確認しています。

### 正答率の計算

正解数を出題数で割り、百分率として小数第一位まで表示しました。

## 既知の制約

- 問題数は収録済みの5問が上限です。
- 問題文をプログラム自身が生成する機能はありません。
- 問題の追加・修正はJSONファイルの編集が必要です。
- 選択肢の表示順は固定です。
- 成績の保存・履歴管理はありません。
- JSONファイルが存在しない場合や破損している場合の例外処理は未実装です。
- GUIには対応していません。
